# Воссоединение: переименование Reunion

Канон сообщества переводит фракцию Reunion как **Воссоединение** (средний род).
Простая замена строки ломала согласование: в старом переводе имя было мужским
(«Реюнион был», «Реюнион захватил», «сам Реюнион»).

`tools/reunion_rename.py` переименовывает фракцию и согласует с ней речь:

- падежные формы: `Реюнион` → `Воссоединение/Воссоединения/Воссоединению/…`;
- составное сказуемое: `был` → `было`, `захватил` → `захватило`,
  `шёл` → `шло`, `должен` → `должно`, `готов` → `готово`,
  возвратные глаголы `-лся` → `-лось`;
- краткие формы и причастия: `таков` → `таково`, `каков` → `каково`,
  `прав` → `право`, `обречён` → `обречено`, `ведомый` → `ведомое`;
- местоимения и определения: `он` → `оно`, `сам` → `само`,
  `нынешний` → `нынешнее`, `Тёплый` → `Тёплое`;
- приложения «движение/силы/лидер/отряды/… Реюнион» получают генитив:
  «движение Воссоединения», «силы Воссоединения».

Сканирование идёт только по текущему предложению и обрывается на тире,
новом имени собственном или новом подлежащем, поэтому чужие сказуемые не
затрагиваются. Функция идемпотентна.

Модуль вызывается дважды, чтобы покрыть всю цепочку сборки:

- `tools/build_ru_merged_pack.py` — после `apply_google_variants`, до записи
  `merged-manifests/99_merged.json`;
- `arklocalizer/custom_pack.py` — после `_apply_google_renames`, потому что
  `ru-overrides/*.json` и `story_ru.tsv` накладываются уже после манифестов.

Тесты: dry-run по собранному `99_merged.json` печатает изменённые токены и
ищет остаточные мужские формы рядом с новым именем.
